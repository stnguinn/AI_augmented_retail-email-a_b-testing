# Notebooks

Planned notebook sequence:

1. `01_experiment_audit.ipynb` — schema, integrity, sample-ratio, and covariate-balance checks
2. `02_confirmatory_analysis.ipynb` — intent-to-treat estimates, intervals, and multiplicity
3. `03_power_and_planning.ipynb` — MDE and future sample-size scenarios
4. `04_segment_exploration.ipynb` — treatment interactions and guarded exploratory analysis
5. `05_executive_decision.ipynb` — concise management recommendation and limitations

Reusable calculations should live in `src/`; notebooks should explain decisions and display outputs rather than hide core logic.
